# AI opdrach 1:
___
om de requirements te installeren run:

    pip install -r requirements.txt
___
roep het programma op met:

    python3 run.py scenariopad

waar scenariopad het pad naar het scenario is bv.

    python3 run.py Scenarios/Scenario1

voor het bijgeleverde `Scenario1`
___
de outputfiles `plan.json` en `statistics.txt` worden in de scenariomap geplaatst
___
om de testen uit te voeren run je:

    pytest
